# Events App

A full-stack event management application built with React, Node.js, Express, and SQLite.

Users can:
- browse events
- create new events
- sign up and log in
- view event details
- search events

## Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS
- DaisyUI
- Vite

### Backend
- Node.js
- Express
- Sequelize
- SQLite
- JWT Authentication

## Features

- Authentication (Sign Up / Sign In)
- Protected routes
- Create events
- Event details page
- Search events
- Responsive UI
- REST API
